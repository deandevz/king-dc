# Mockups

Telas desenhadas antes do código, em HTML estático de 1440×900. Abra qualquer `.dc.html`
no browser. O `canvas.json` de cada pasta descreve a posição de cada tela no canvas e as
anotações de direção.

- `minimal/` é a direção implementada: duas colunas, vidro escuro, um accent menta. Os
  tokens e as medidas estão resumidos em [`../docs/INTERFACE.md`](../docs/INTERFACE.md).
- `classico/` é a alternativa descartada, mais próxima do layout do Discord, com barra de
  servidores e uma tela de live. Fica como registro.

Os mockups não têm controle funcional. Onde a implementação difere deles está listado no
fim do `INTERFACE.md`.
